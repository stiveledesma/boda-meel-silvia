# Invitación V11.2 — Meel & Silvia

Sitio estático con visual Clásico/Azul, página de pase `entrada/` y control de recepción `recepcion/`.

Antes de probar, edita una sola URL en `assets/api-config.js` apuntando al Apps Script V11.2 **DE PRUEBAS**.

Este directorio contiene únicamente código e imágenes estáticas. No contiene contraseñas ni configuración privada del servidor. Los tokens privados de los invitados se consultan desde Google Sheets únicamente cuando el usuario abre su enlace personalizado.
