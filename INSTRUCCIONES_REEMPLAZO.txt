MEEL & SILVIA — SELECTOR CLÁSICO / AZUL
=====================================

Esta versión elimina la necesidad de usar /azul/.
Todo funciona desde el mismo index.html.

URL clásica:
https://stiveledesma.github.io/boda-meel-silvia/

URL azul directa:
https://stiveledesma.github.io/boda-meel-silvia/?tema=azul

También hay un botón arriba para cambiar entre ambos estilos.

PARA INSTALAR SOBRE TU REPO:
1. Haz un respaldo/commit de tu estado actual (ya lo hiciste).
2. Extrae este ZIP.
3. Copia el contenido de `meel_silvia_exclusive_v8_dual` dentro de:
   C:\Dev\boda-meel-silvia
4. Acepta reemplazar archivos.
5. NO borres tu `assets\music.mp3`.
6. Prueba localmente:
   python -m http.server 8080
7. Abre:
   http://localhost:8080/
   http://localhost:8080/?tema=azul
8. Si todo está bien:
   git add .
   git commit -m "Agregar selector Clasico Azul"
   git push origin main

GitHub Pages actualizará el mismo enlace automáticamente.
