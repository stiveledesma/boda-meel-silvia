# Meel & Silvia — versión dual Clásico / Azul

Esta versión conserva una sola página y una sola URL de GitHub Pages.

## Selector visual
Arriba aparece un selector **Clásico / Azul**. Cambia el tema sin recargar ni navegar a `/azul/`.

- Clásico: `https://stiveledesma.github.io/boda-meel-silvia/`
- Azul directo: `https://stiveledesma.github.io/boda-meel-silvia/?tema=azul`

La elección se guarda en `localStorage`, por lo que al volver a abrir la invitación se conserva el último tema usado.

## CSS
- `assets/styles-classic.css` — V6 clásica.
- `assets/styles-blue.css` — variante azul.

## Música
La página intenta usar primero `assets/music.mp3` y conserva `assets/nuestra_cancion.wav` como respaldo. Como el MP3 real está en tu repositorio local, comprueba que siga allí después de copiar estos archivos.
